## 📊 Sales Analytics Dashboard

## 📌 Project Overview

This project focuses on transforming raw sales data into meaningful visual insights using Python and data visualization tools. The objective is to analyze sales performance, identify trends, and present findings through charts, graphs, and an interactive dashboard.

The project demonstrates essential Data Analyst skills such as data cleaning, data visualization, dashboard creation, and business storytelling.

---

## 🎯 Objectives

- Transform raw sales data into visual formats.
- Identify sales trends and business patterns.
- Compare performance across products and countries.
- Create an interactive dashboard for data exploration.
- Present insights that support business decision-making.

## 📈 Visualizations Created

### 1. Sales by Product Line
Analyzes revenue generated by each product category and identifies the highest-performing products.

### 2. Monthly Sales Trend
Shows monthly sales fluctuations and helps identify seasonal demand patterns.

### 3. Top Countries by Sales
Compares sales performance across countries and highlights key markets.

### 4. Deal Size Distribution
Visualizes the contribution of Small, Medium, and Large deals to overall revenue.

### 5. Correlation Heatmap
Displays relationships between numerical variables and reveals hidden patterns in the dataset.

---

## 📊 Interactive Dashboard

The project includes a Streamlit dashboard featuring:

- Total Sales KPI
- Total Orders KPI
- Country Count KPI
- Product Line Analysis
- Monthly Sales Trends
- Top Countries Analysis
- Dataset Preview

Run the dashboard using:

```bash
streamlit run dashboard.py
```

---

## 🔍 Key Insights

- Classic Cars generated the highest sales revenue.
- Medium-sized deals contributed significantly to overall sales.
- Sales showed noticeable seasonal trends across different months.
- A few countries accounted for a major share of total revenue.
- Product performance varied considerably across categories.

## 🚀 How to Run the Project

### Clone the Repository

```bash
git clone <repository-url>
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Generate Visualizations

```bash
python visualization.py
```

### Launch Dashboard

```bash
streamlit run dashboard.py
```
